# minhas-skills

Minha lista de skills, plugins e programas para o Claude Code.

- `skills.txt` — skills (repositório, pasta, nome)
- `plugins.txt` — plugins do Claude Code
- `npm-tools.txt` — programas de linha de comando
- `install.sh` — instala tudo o que está nas listas

## Setup script do ambiente na nuvem (colar uma vez)

```bash
curl -fsSL https://raw.githubusercontent.com/jjfjason/minhas-skills/main/install.sh | bash
```

## No meu computador

```bash
git clone https://github.com/jjfjason/minhas-skills && bash minhas-skills/install.sh
```
